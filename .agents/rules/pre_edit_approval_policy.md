# Hyper-Concise Pre-Edit Approval Policy

## Core Invariant
- **Always explain BEFORE editing code**:
  - Before modifying any source file (`.py`, etc.), present a super-fast, punchy explanation.
  - **Format (Bite-sized, punchy, ADHD-friendly)**:
    - 🎯 **מה המטרה:** (1-2 משפטים חדים)
    - 🛠️ **איזה קובץ משתנה:** (`file_name.py`)
    - ⚡ **מה בדיוק משתנה:** (2-3 בולטים קצרים וממוקדים)
    - ❓ **בקשת אישור מפורשת מהמשתמש**.

## Approval Protocol
- Wait for the user's explicit approval ("סע", "קדימה", "מאושר") before executing any code changes.
